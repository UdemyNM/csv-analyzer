# 01. 要件定義

## 1. 目的
CSVファイルをアップロードして分析（集計・グラフ・統計）し、その結果をログインしたメンバー間で共有するWebアプリ。

## 2. 確定した前提（ヒアリング結果）
| 項目 | 決定内容 |
|---|---|
| 分析内容 | 集計・フィルタ・並べ替え / グラフ可視化 / 統計・相関分析 |
| 共有方法 | ログインメンバー間で閲覧共有 |
| 規模 | 〜10人、CSV 〜10MB |
| 環境 | 第1段階: ローカル（Vite開発サーバー）→ 最終: Supabase 無料プラン |
| CSVの形 | 1行目ヘッダー、2行目以降データ（固定）。列構成・内容はCSVごとに任意 |
| 文字コード | UTF-8 / Shift_JIS を自動判定して両対応 |
| 権限 | アップロード者がデータセットごとに「全員 / 自分のみ」を選択 |
| 保存対象 | CSV原本 + グラフ・フィルタ設定（ビュー）を保存して共有 |
| UI | React（CLAUDE.md のルール） |

## 3. 機能要件
### 3.1 認証・ユーザー
- FR-01 メール＋パスワードでログイン／ログアウトできる。**サインアップ画面は作らない**（Supabase側でサインアップを無効化し、管理者がダッシュボードでユーザーを作成する）
- FR-02 未ログインでは一覧・閲覧・アップロードにアクセスできない

### 3.2 CSVデータセット管理
- FR-10 CSVをアップロードできる（拡張子 .csv、10MBまで）。一覧画面のドロップ枠にドラッグ＆ドロップ（または「ファイルを選ぶ」）すると、アップロードして新しい分析画面が開く
- FR-11 文字コード（UTF-8 / Shift_JIS）を自動判定して読み込む
- FR-12 公開範囲（全員 / 自分のみ）を選べる。アップロード画面はなくしたため、アップロード後に詳細画面で切り替える（アップロード直後は「自分のみ」）
- FR-13 データセット一覧を表示（自分のもの＋全員公開のもの）
- FR-14 作成者のみ、名前変更・公開範囲変更・削除ができる
- FR-15 不正なCSV（空、ヘッダーなし、サイズ超過）は分かりやすいエラーを出す

### 3.3 分析
- FR-20 表形式でデータをプレビューできる（大量行は仮想スクロール/ページング）
- FR-21 列の型（数値/文字列/日付）を自動判定する
- FR-22 フィルタ（列ごとの条件）と並べ替えができる
- FR-23 集計ができる（グループ化＋合計・平均・件数・最大・最小）
- FR-24 グラフを作成できる（棒・折れ線・円・散布図。軸と集計方法を選択）
- FR-25 基本統計量を表示する（件数・平均・中央値・標準偏差・最小・最大・欠損数）
- FR-26 数値列間の相関係数（相関行列）を表示する
- FR-27 統計用語（件数・平均・中央値・標準偏差・最小・最大・相関）の横に「？」を置き、押すと短い解説を表示する
- FR-28 分析画面は、データ表 → グラフ → 集計 → 統計・相関を縦1列に並べ、各セクションを開閉ボタンで表示/非表示にできる

### 3.4 ビュー（設定の保存と共有）
- FR-30 現在のフィルタ・並べ替え・集計・グラフ設定を「ビュー」として名前を付けて保存できる
- FR-31 データセットを閲覧できる人は、そのビューも閲覧できる
- FR-32 ビューの編集・削除は作成者のみ

## 4. 非機能要件
| 区分 | 要件 |
|---|---|
| 性能 | 10MB・数万行のCSVで、フィルタ/集計が体感2秒以内。パースでUIを固めない（Web Worker） |
| セキュリティ | 権限判定はサーバー側（Supabase RLS）で行う。画面の出し分けだけに頼らない |
| プライバシー | CSV原本はprivateバケットに保存し、署名付きURL/認可経由でのみ取得 |
| 可用性 | 小規模のため冗長化なし。Supabase無料枠の制約内で運用 |
| 使いやすさ | レスポンシブ対応、日本語UI |
| 保守性 | 保存層をインターフェースで抽象化し、ローカル実装とSupabase実装を差し替え可能に |
| テスト | TDD。分析ロジックは純粋関数としてユニットテスト |

## 5. 制約
- Supabase無料プランの上限内（DB容量・Storage容量・ファイル上限・停止ポリシー）。数値は**実装前に最新の公式ドキュメントで確認**する
- ビルド/テストツール（候補: Vite + Vitest + React Testing Library）は導入前にユーザー確認
- ライブラリ追加は都度確認（候補は 04 を参照）

## 6. スコープ外（初期リリース）
- リアルタイム共同編集、コメント機能
- 個別ユーザー/グループ単位の権限指定
- 外部公開リンク（ログイン不要の共有）
- AIによる自動分析・要約
- 10MB超・数十万行規模のデータ
- 固定フォーマット（テンプレート）対応
- グラフ画像・集計結果CSVのダウンロード（OQ-3）
- セルフサインアップ、メール確認、パスワード再設定画面（OQ-1）
