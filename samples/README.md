# 演習用の CSV（3 つ）

データ分析ツールで読み込む練習用の CSV です。どれも作り物のデータで、1 行目がヘッダーです。読み取りの難しさが、1 → 2 → 3 の順に上がります。

| ファイル | 中身 | 文字コード・改行 | 読み取りで気をつける所 |
|---|---|---|---|
| `sales_2024q1.csv` | 売上の明細（2024 年 1〜3 月、4 店舗 × 3 商品、毎日）1,092 行 | UTF-8（BOM なし）・LF | 素直な形。日付は `2024-01-01` の形。数字にカンマは無い |
| `sales_excel_sjis.csv` | 店舗別・商品別の月ごとの売上（Excel から書き出した表）13 行 | Shift_JIS・CRLF | 文字化けしやすい（Shift_JIS）。月が横に並ぶ（1月・2月・3月）。数字がカンマ付きの文字（`"116,040"`）。最後の行が「合計」 |
| `survey.csv` | 来店アンケートの回答 200 件 | UTF-8（BOM 付き）・LF | 「感想」のセルに、改行・半角カンマ・二重引用符が入っている（引用符で囲まれている）。空欄がある（年代・感想・再来店）。「買った商品」は `りんご;みかん` のように 1 つのセルに複数 |

## 列

- `sales_2024q1.csv`：日付・店舗・商品・数量・単価・売上（売上 ＝ 数量 × 単価）
- `sales_excel_sjis.csv`：店舗・商品・1月・2月・3月・合計
- `survey.csv`：回答ID・回答日時（`2024-01-01 12:51:09` の形）・店舗・年代・満足度（1〜5）・買った商品・感想・再来店（はい／いいえ／空欄）

## 確かめ方の例

- `sales_excel_sjis.csv` の各月の数字は、`sales_2024q1.csv` を店舗・商品・月ごとに合計した値と一致する。2 つを読み込んで、同じ合計が出れば、両方を正しく読めている。
- 「合計」の行は、データではなく合計なので、集計に含めると 2 倍になる。
- `survey.csv` の「感想」が途中で切れたり、列がずれたりしていなければ、引用符の中の改行とカンマを正しく読めている。
